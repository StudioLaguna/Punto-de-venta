# DECISIONES.md — registro de decisiones no especificadas (regla 7)

1. **Migraciones embebidas + archivos**: `migrations/*.sql` es la referencia; `connection.ts` los lee de disco en dev y de `resources/migrations` en prod. Sin archivos (empaquetado parcial), el arranque no falla: las tablas se crean igual vía `CREATE TABLE IF NOT EXISTS` del propio loader. Simple y offline.
2. **Reporte diario por día UTC**: `created_at` es ISO UTC; `reports.daily({date})` filtra `dateT00:00–23:59Z`. En una sola caja con corte a medianoche local hay ±horas de deriva; se documenta y se evita añadir librerías de zona horaria en v1.
3. **PIN con SHA-256, sin bcrypt**: evita dependencia nativa extra; suficiente para un solo admin local en v1. Registrar auditoría de anulaciones queda para “qué revisar al crecer”.
4. **Respaldo con `db.backup()` + checkpoint WAL + fallback a copia**: `better-sqlite3` expone backup async; se hace best-effort y se verifica tamaño, con `PRAGMA wal_checkpoint(TRUNCATE)` antes. Restaurar guarda `pos.db.prev` y borra `-wal/-shm`.
5. **E2E Playwright a nivel de servicios**: el flujo “crear→entrada→vender→anular→reporte” corre con Playwright importando los mismos servicios que usa el IPC, garantizando paridad sin necesitar display de Electron en CI. Smoke de UI opcional con `E2E_WEB=1`.
6. **Sin react-router ni CSS framework**: pestañas por estado + CSS propio para instalador liviano y UI táctil/teclado rápida.
7. **better-sqlite3 v12 + Electron 35**: v11 no trae prebuild para Node 24 (intentaba compilar con VS); v12.11.1 sí. Además `connection.ts` resuelve el `.node` y lo pasa como `nativeBinding`, porque el paquete `bindings` falla bajo el transformador de Playwright. `npm test`/`e2e` pasan en Node puro; el `dist` usa `electron-builder` con rebuild automático.
8. **Instalador sin firma (`win.signAndEditExecutable: false`)**: electron-builder descarga `winCodeSign` para editar el .exe aunque no haya certificado; extraerlo exige privilegio de symlinks (modo desarrollador o admin) y fallaba con `exit status 2`. Se desactiva la edición/firma: el instalador NSIS se genera igual, Windows mostrará el aviso estándar de editor desconocido. Para firmar en el futuro, conseguir certificado y revertir el flag.
